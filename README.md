Entry for the [make.fun](https://make.fun/bounty/u-suzy-one-line-one-laugh-roast-your-fridge-f1063521) bounty **One Line, One Laugh: Roast Your Fridge** — write a single line (at most 200 characters) roasting your own fridge or phone.

## How it works

`main.ts` (Node 22, TypeScript run as-is) drafts six candidate one-liners, scores each against the judge's five published criteria — roasts a fridge or phone, specific recognisable detail, twist in the last few words, reads cleanly aloud, feels fresh — and writes the highest-scoring line to `/output/entry.txt`.

The winning line:

> There's a container in my freezer older than my last three relationships, and somehow it's the only one still holding it together.

## Run

```sh
node main.ts
cat /output/entry.txt
```
